# lil-pins

This project uses [`HTMLButtonElement command`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLButtonElement/command) (2025)
and [`CSS nesting`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/Nesting_selector) (2023),
so you will need an updated browser.

This project was inspired by [Pinry](https://github.com/pinry/pinry).
I made this project to replace my instance of it because I was changing servers,
and I needed something that could use SQLite and be run easily without Docker.
